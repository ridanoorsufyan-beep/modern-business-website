# Modern Business Website

A clean, modern and responsive business website built with HTML5, CSS3 and JavaScript.

## Live Demo
https://ridanoorsufyan-beep.github.io/modern-business-website/

## Features
- Responsive design
- Dark and Light mode
- Home, About and Services sections
- Portfolio section
- Testimonials
- Contact form with validation
- Smooth navigation
- Back to top button

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
